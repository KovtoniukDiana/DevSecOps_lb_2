## Секрети і конфігурація

Застосунок читає налаштування **лише із середовища**. Секрети в код і в Git не потрапляють.

| Змінна | Обов'язкова | Опис |
| --- | --- | --- |
| `DRAGON_DB_URL` | так | Рядок підключення до бази медичних карток: `dragondb://<користувач>:<пароль>@<хост>/<база>` |
| `APP_ENV` | так | Режим роботи: `dev` або `prod` |
| `LOG_LEVEL` | ні | Рівень журналу, за замовчуванням `INFO` |

**Де взяти значення.** Для розробки: `cp .env.example .env` і впишіть дані тестової бази (їх видає власник проєкту).
У CI значення беруться із секретів платформи, у продакшні — з менеджера секретів. Файл `.env` ігнорується Git.

Якщо змінної немає, застосунок зупиняється з повідомленням, у якому названо змінну, але не показано значення.
Для виведення рядка підключення в журнал використовуйте `mask_dsn()`.

**Встановлення хуків** (один раз після клонування):

```bash
pip install pre-commit && pre-commit install
```

Хуки зупиняють коміт із паролем у рядку `dragondb://…`, приватним ключем, великим файлом або маркером конфлікту злиття.
Якщо хук знайшов справжній секрет — не обходьте його (`--no-verify`): відкличте пароль, повідомте власника проєкту, очистіть історію.
